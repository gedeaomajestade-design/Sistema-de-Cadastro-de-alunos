Este Sistema simula uma cadastro de uma escola.
Ela tem como objectivo cadastrar o Aluno, usando os dados do aluno como ;
nome, cpf, curso, turma e periodo.
essas informações são introduzidas pelo usuario.
o sistema pede e o usuario vai preenchendo de acordo com o que lhe foi pedido
e no final aparece a lista dos Alunos cadastrados com nome, cpf, curso turma e o periodo escolhdo pelo ususario.
